# ADR-007: 首次运行静默开启开机自启（维持现状）

- 状态：已接受（2026-08-12，架构复盘质询轮 4）
- 关联：[[0006-ui-context-capture-fix]]、[[glossary]]

## 背景

`TrayApp` 构造器在首次运行时检测自启未开启即 `Autostart.Set(true)` 静默写入注册表
Run 键，无询问、无提示；右键菜单"开机自启"勾选项提供关闭出口。质询提出三个方向：
静默（现状）、静默 + 告知性 balloon、默认不自启。

## 决策

- **维持静默自启**（代码不变）。理由：
  - 监控工具的价值在于"一直在"——若默认不自启、等用户主动勾选，多数人忘记开启，
    监控形同虚设（首启自启是唯一可靠的"开箱即用"路径）；
  - 告知性 balloon 在首启时与登录提示挤成两条通知，聒噪且收益低；
  - 菜单勾选项已提供足够低成本的关闭出口，单用户工具无需更高规格的征询流程。

## 影响

- 正向：首次运行后监控连续，无需用户记得开自启。
- 负向：接受"静默写注册表"的观感风险（菜单可关、README 可注明）。

## 验收标准

- 首次运行后 Run 键存在；菜单勾选项可关闭并持久生效。
